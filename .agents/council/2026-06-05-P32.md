## Issues Identified

### 1. Starzec 2026 omitido (Ambos juízes: WARN)
O 4º precedente (Starzec & Starzec 2026, MOTSP com feromônio multidimensional) não está no LaTeX, BibTeX, nem vault. É o precedente mais próximo do domínio do TCC (MOTSP é TSP multi-objetivo).

**Ação:** Adicionar BibTeX + vault note + citação no parágrafo, com nota de que é dataset/repositório institucional.

### 2. Gap de scheduling não investigado (Judge 2: WARN)
A nota de originalidade classifica ACO para scheduling com 3 índices como "risco real", mas nenhuma busca foi feita nesse domínio.

**Ação:** Documentar explicitamente como limitação conhecida na nota de originalidade.

### 3. Limitações de busca não declaradas no LaTeX (Judge 2: WARN)
O hedge "na literatura consultada" não especifica escopo, fontes ou limitações.

**Ação:** Expandir parágrafo ou nota de rodapé com disclosure das limitações (CAPTCHA, rate-limiting).

### 4. "Necessária" → "natural" (Judge 2: NICE)
"Adaptação necessária" implica inexistência de alternativas (turn-cost routing via expansão de grafo existe).

**Ação:** Substituir por "adaptação natural" ou "motivada pela estrutura do TSP-SD-ATP".

### 5. Status das notas vault (Judge 2: NICE)
As 3 notas estão `nao-lido`. Ler abstracts e atualizar.

**Ação:** Atualizar status para `resumo-lido` após verificação dos abstracts.
