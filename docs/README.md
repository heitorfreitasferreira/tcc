# Documentacao do Framework Agentico

Esta pasta documenta os componentes do framework agentico de pesquisa do TCC.

## Indice

| Documento | Componente |
|---|---|
| `arquitetura.md` | Arquitetura geral, camadas e fluxo de dados |
| `repositorio.md` | Estrutura geral do TCC: `src`, `vault`, `monografia` e framework |
| `roadmap.md` | Fila de tarefas, fases, eventos e bases Obsidian |
| `comandos.md` | Slash commands e responsabilidades operacionais |
| `literatura.md` | Busca academica, incorporacao, PDFs e BibTeX |
| `vault.md` | Vault semantico, tags, papers, claims e bases |
| `validacao.md` | Council, auditorias e protocolo anti-alucinacao |
| `experimentos.md` | Experimentos, resultados e relacao com claims |
| `monografia.md` | Escrita LaTeX, compilacao e referencias |
| `skills.md` | Skills por fase e dominio |
| `scripts.md` | Scripts auxiliares e contratos |
| `go-cli.md` | CLI Go usado como motor experimental |
| `analise-web-visualizador.md` | Analise existente do visualizador web |

## Como Navegar

- Comece por `repositorio.md` e `arquitetura.md` para entender o sistema.
- Use `roadmap.md` e `comandos.md` para operar a fila.
- Use `literatura.md`, `vault.md` e `validacao.md` para tarefas academicas.
- Use `experimentos.md` e `go-cli.md` para trabalhos com dados.
- Use `monografia.md` para escrita e compilacao.
